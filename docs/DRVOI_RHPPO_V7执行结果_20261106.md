# DRVOI-RHPPO V7 执行结果（2026-11-06）

本次执行严格遵循 `DRVOI-RHPPO V7：WVR响应重建与跨步VOI执行协议` 的阶段门禁。P0、三种子冻结B0、P1R响应可识别性和P1C概率校准已经完成。P1R主门禁失败，因此P1Q、O0、10万至50万步短筛选和1000万步训练均未启动，`v7_long_training_authorized` 保持为 `false`。

## 3. 正式响应数据

正式实验使用采集种子6185、7185和8185，分别建立D-cover、D-onpolicy和D-reactive。每个数据源、每个对手、每个种子均按完整回合分为train 120、validation 30、calibration 30和test 30；红蓝角色各半。D-cover在每个对手与划分内精确保持50%均匀合法动作回合和50%冻结B0回合。

共生成9份正式数据文件。每份包含630个完整回合，三类对手各210回合；所有文件均满足末步终止、无回合内提前终止标记、回合ID唯一以及源代码/协议SHA-256匹配。

## 4. P1R主门禁

主检验为D-onpolicy、Rel、Δ=3、冻结B0 belief上下文下的M3相对M2。

| 指标 | 正式结果 | 预注册要求 | 判定 |
|---|---:|---:|---|
| 宏平均ΔNLL/维 | 0.00808 | ≥0.05 | 失败 |
| ΔNLL回合bootstrap 95% CI | [0.00661, 0.00947] | 下界>0 | 通过 |
| 正确动作相对置换动作增益/维 | 0.01863 | >0 | 通过 |
| 置换增益95% CI | [0.01706, 0.02024] | 下界>0 | 通过 |
| 主模型原始梯度峰值 | 70.26 | ≤1000且有限 | 通过 |

因此，动作对未来相对动力学具有统计上可检测的信息，但信息增量只有预注册最小效应量的约16.2%，不足以支持主G1，也不足以授权基于该响应模型的VOI机制。

灵敏度实验中，多数组合的ΔNLL置信区间为正，但效应量仍小；cover/Rel/Δ=3/direct甚至出现条件模型劣于无动作模型。D-reactive正控制在direct上下文通过，但belief上下文的ΔNLL置信区间跨零，说明当前B0 belief会削弱已知动作—响应关系。两个次要direct/Δ=1实验的原始梯度略高于1000；主模型没有该问题，但全套数值健康门禁按预注册规则仍判失败。

## 5. P1C校准门禁

主模型校准通过：总体90%覆盖率为0.9072，逐维范围为0.8952–0.9279，对手×阶段最低覆盖率为0.8857，且上下方差边界触及率均为0。该结果说明P1R失败不能归因于明显的方差失校准。

## 7. 可证伪结论

在当前WVR平台、观测v4、0.2秒策略周期、Rel响应定义和Δ=3（0.6秒）条件下，学习方动作能够提供真实但很小的额外响应预测信息。该效应没有达到方案预注册的0.05 nats/维阈值，不能据此继续声称现有DRVOI响应链路具有足够的决策价值。

若继续研究，应作为新的、重新预注册的V7.1问题开展，而不是修改本次阈值或复用本次test集。可选方向包括重新定义更贴近动作因果效应的响应变量、使用显式系统辨识belief替代策略GRU belief，或把研究问题从“对手响应VOI”改为“可控相对动力学预测”；任何新方案必须使用新的确认性test回合。
