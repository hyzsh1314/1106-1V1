# DRVOI-RHPPO V7.1 History-Response 预注册协议

## 1. 决策与边界

V7 的主 G1 失败结论保持不变，P1Q、O0、短筛选和长训练继续禁止。V7.1 只检验一个问题：在保持 Rel、Δ=3、D-onpolicy、continuous-only 和0.05 nats/维门槛不变时，显式三步观测与动作历史是否能恢复足够的动作条件响应信息。

本轮不得更换主响应维、挑选Δ、降低阈值、复用V7 test或增加大型表征网络。若V7.1主检验失败，停止当前WVR上的DRVOI-Rel主线。

## 2. 历史输入

历史长度固定为L=3：`H_t=[o_(t-2),o_(t-1),o_t]`，`A_t=[a_(t-2),a_(t-1),a_t]`。观测历史展平为117维，并拼接3维有效掩码；动作历史为39维multi-one-hot。

H1接收观测历史、有效掩码和完整动作历史；H0接收相同观测历史与掩码，但39维动作通道全部置零。两模型采用相同两层256单元MLP、5成员集成、初始化、成员回合掩码、批次和早停规则。动作输入权重初始化为零。

错误延迟负控制固定为不重叠的旧窗口 `[a_(t-5),a_(t-4),a_(t-3)]`，不得包含 reactive 的已知因果动作 `a_(t-2)`。这避免把仍含因果动作的平移窗口误当成负控制。负控制只替换已拟合H1在评估时的动作输入，不另行训练一个能够重新解释错位索引的模型。

回合开始缺少的观测填零，缺少的动作用中性动作 `[1,2,1,0]` 编码，同时对应有效掩码为0。reset、终止和auto-reset必须清除全部历史，不得读取上一回合状态。

## 3. 数据与外层协议

主数据生成策略固定为冻结的1M B0 seed85，不依据其已观察任务表现重新挑选。采集种子固定为10185、11185、12185、13185和14185。每个种子、每个对手使用train 120、validation 30、calibration 30和test 30个完整回合，并保持红蓝平衡。

开发阶段仅允许访问train/validation。只有P1D因果对齐、reactive正控制和数值健康全部通过并提交冻结配置后，才能生成或打开确认性test。

确认性评估采用5折leave-one-collection-seed-out。每折完整留出一个采集seed的test，其余seed仅使用train/validation/calibration；任何seed的test均不得用于训练、早停或校准选择。

## 4. 开发门禁

P1D必须验证：历史缓存在reset边界无串线；reactive正确历史优于零历史和错误延迟历史；已知有效动作头可被单头删除/置换诊断识别；H1在D-onpolicy validation相对H0呈稳定正增益；正式模型不存在NaN/Inf、方差边界塌缩或未解释的原始梯度大于1000。

D-reactive是独立软件正控制，不参与主D-onpolicy结论。学习方动作使用合法均匀随机干预，打断确定性B0造成的“观测历史可推断动作”混杂。为避免冻结LAG低层控制器的循环隐状态把声明的两步高层延迟扩展为未知物理时滞，reactive开发采集将 `a_(t-2)` 的alt、heading和speed头通过预注册、有界的直接舵面/油门映射作用于对手；仍使用同一Torch 6-DoF动力学。随机干预与该映射均不得进入D-onpolicy、奖励或在线VOI。

配对干预探针仅用于开发诊断。它必须从同一完整仿真快照、低层控制器隐状态和RNG出发比较动作与中性动作，输出逐维效应RMS和方向一致性；反事实差值不得作为在线响应标签或VOI输入。

## 5. 主统计与确认性门禁

唯一主检验是Rel、Δ=3、D-onpolicy、H1对H0。每个外层seed先计算回合等权ΔNLL/维和正确历史相对同对手×阶段置换历史的NLL增益，再以5个外层seed为独立单元计算双侧小样本t区间。

G1要求外层平均ΔNLL/维至少0.05、95%区间下界大于0且至少4/5 seed点估计为正；置换增益及区间下界均大于0。Reactive-H1/H0的Opp效应及区间下界必须大于0，且正确延迟历史必须优于错误延迟历史。

G2沿用V7：校准尺度只由calibration NLL选择；test总体90%覆盖在 `[0.85,0.95]`，逐维在 `[0.75,0.98]`，主对手×阶段覆盖不低于0.75，且报告PIT、NLL、RMSE和边界触及率。

## 6. 后续授权

只有G0、G1、reactive、G2和B0 seed185/285方向稳健性全部通过，才允许修复并运行新版P1Q。当前配置中的P1Q、O0、短筛选和长训练授权全部为false，且不允许手工覆盖。

## 7. 停止规则

以下任一情况立即停止DRVOI-Rel：正确动作历史下reactive仍失败；H1在开发validation无稳定增益；新确认性主效应小于0.05；效应只在个别seed、对手或D-cover成立；需要复用旧test、删除响应维、降低阈值或挑选Δ；B0稳健性复核方向反转；后续Q只能读取任意响应扰动而不能通过结构化动作排序。
