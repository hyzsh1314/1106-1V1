# DRVOI-RHPPO V7.3 回报时间尺度执行结果

## 结论

V7.3 已完成3、12、30、120决策步和完整终局回报的共享轨迹筛选。没有任何时间尺度同时满足机械 oracle 与 `full_observation` 的动作排序和最优动作遗憾门槛，因此冻结为 `RETURN_TARGET_NO_GO`。

formal-test seed 66185 未生成、未访问；新响应目标、P1Q、O0 和长训练均不授权。

## 实验控制

- train seeds：63185、64185，共768个上下文；
- validation seed：65185，共96个上下文；
- 每个上下文枚举90个动作；
- 五种回报来自同一动作轨迹，终止后保持吸收态零增量；
- 三种状态表示使用同一 joint-dueling critic、损失、训练预算和早停规则；
- 完整终局分支全部到达环境真实终止。

## 关键结果

下表给出 validation 的“排序准确率 / 归一化 argmax 遗憾”。

| 回报尺度 | V7.1表示 | 完整未来观测 | 机械oracle |
|---|---:|---:|---:|
| 3步 | 0.574 / 0.356 | 0.577 / 0.353 | 0.579 / 0.380 |
| 12步 | 0.654 / 0.271 | 0.639 / 0.271 | 0.622 / 0.327 |
| 30步 | 0.581 / 0.318 | 0.587 / 0.331 | 0.582 / 0.306 |
| 120步 | 0.500 / 0.382 | 0.511 / 0.352 | 0.520 / 0.343 |
| 完整终局 | 0.502 / 0.449 | 0.522 / 0.445 | 0.525 / 0.403 |

12步目标的成对排序最好，说明局部动作效应并非完全不可学习；但其最优动作遗憾仍为0.27–0.33，远高于0.10门槛。30步以上排序快速衰减，120步和完整终局接近随机。

## 方法学解释

当前离散高层动作与低层控制器的组合能够支持粗略的局部动作比较，但不足以可靠选出最优动作。DRVOI 需要对不同响应候选下的最优后续动作进行比较，因此仅有成对相关性而没有低 argmax 遗憾仍会产生不可信 VOI。

继续扩大 critic、增加训练 epoch 或降低门槛不能解决该问题。若仍继续该研究路线，需要重新定义候选动作价值，例如使用动作集合/技能级价值、top-k稳健价值或短期模型预测控制，而不能把当前 Q 结果用于在线内在奖励。
