# DRVOI-RHPPO V6：WVR Torch 平台适配与执行协议

> **执行状态（2026-11-05）**：P0 通过；P1 的 G3–G7 通过，但按回合隔离、回合 bootstrap 和动作置换负控制复验后，G1（动作条件 ΔNLL）与 G2（side ECE）失败。因此 V6 动作条件 DRVOI 主线已按第 6 节停止，未授权启动 1000 万步 O0/O2/O3/O4。完整决策见 `runs/drvoi_rhppo/P1_GATE_DECISION.md`。

## 1. 适配边界

源方案面向 LAG 的 21 维观测、90 个高层联合动作和 JSBSim 环境。本实现不修改当前已经冻结的 Torch 6DoF 环境、动力学、武器、奖励、终止条件、观测或已有 PPO/分层 PPO 实验脚本。DRVOI-RHPPO 及其消融和对比方法全部使用新建脚本和独立输出目录。

保留的算法不变量如下：

1. VOI 必须在 `env.step` 前计算，不能读取未来观测、奖励或终止信号。
2. LP 必须在当前响应目标进入训练池前做预序评分。
3. 交叉拟合 Q 只学习外在环境奖励；同一回合只能属于 Q_A 或 Q_B 的一个折。
4. 内在奖励不含 beta；beta 只在 `A_ext + beta * A_int` 中施加一次。
5. 评估冻结 Actor、归一化统计、响应模型和 Q，不计算内在奖励。

## 2. 平台接口映射

|---|---|---|
| 物理环境 | JSBSim F-16 | 冻结的 Torch 6DoF F-16/导弹批量环境 |
| 物理频率 | 60 Hz | 60 Hz |
| 决策间隔 | 12 个物理子步，即 0.2 s | 12 个物理子步，即 0.2 s |
| 单机观测 | 21 维 | v4 观测 39 维 |
| 高层动作 | `[3,5,3,2]`，90 个联合动作 | `[3,5,3,2]`，90 个联合动作 |
| 低层控制 | LAG BaselineActor | 当前冻结 BaselineActor，与已有 PPO 共用 |
| 外在奖励 | LAG 原生奖励 | 当前冻结 `competitive` 奖励 |

当前 v4 观测的关键索引为：高度 `0`，本机速度 `5:8`，相对纵向速度 `9`，高度差 `10`，AO `11`，TA `12`，距离 `13`，侧向标志 `14`，双方 NED 速度 `15:21`，弹药 `21:23`，合法发射掩码 `23`，三维 LOS 角 `24:26`，LOS 角速率 `26:28`，闭合速度 `28`，导弹威胁状态 `29:39`。

## 3. 本平台响应向量

响应模型只能使用策略已获得的 39 维合法观测。连续响应状态定义为：

`z_cont = [obs[9], obs[10], sin(obs[11]), cos(obs[11]), sin(obs[12]), cos(obs[12]), obs[13], obs[24], obs[25], obs[26], obs[27], obs[28]]`

离散响应为 `side = obs[14] in {-1, 0, 1}`，映射为三分类。训练目标为相邻决策时刻连续响应之差和下一时刻 side。角度先转正余弦再做差，不能对 AO/TA 原角度直接线性差分。

导弹威胁特征 `29:39` 暂不进入响应预测主目标，因为它们同时受双方发射行为和导弹飞行动力学影响，会混入非对手机动响应。它们仍保留在 RHPPO 信念输入中。后续可作为独立响应头消融，不得与主结果混用。

## 4. RHPPO 骨干适配

新骨干使用 39 维观测和上一步 13 维 multi-one-hot 动作，经动作嵌入和 GRU 得到循环信念。Actor 输出四个分类头，联合 log-prob 为四头 log-prob 之和。外在和内在价值头分离，按完整序列训练，终止清空隐状态；burn-in 片段只恢复隐状态，不进入 PPO 损失。

已有标准 PPO 和分层 PPO 继续作为原样基线，不在其脚本中嵌入 DRVOI 模块。

## 5. DRVOI 模块适配

- 响应集成：5 个成员，输入停止梯度的信念与 13 维动作编码，输出 12 维连续增量的均值/方差和 3 类 side logits。
- 候选采样：每成员 4 个候选，合计 20；连续量使用成对反向采样。
- Q 模型：双折 Q_A/Q_B，状态上下文为信念、当前动作和候选响应；下一战术动作仍为 90 个联合动作，以 13 维 multi-one-hot 嵌入评估。
- VOI：A 选择/B 评估与 B 选择/A 评估取平均；日志同时保存 T1、T2、有符号 V_CF 和裁剪后的 V+。
- LP：当前响应集成与延迟快照在新样本上的预序 NLL 改善。
- ENS-MI：连续矩匹配熵差代理与 side 分类 BALD 分开记录。
- 内在奖励：首先验证 O0 VOI-only；LP、ENS-MI、加性和乘积只在 O0 通过后依次进入。

## 6. 执行顺序和停止规则

1. **P0 平台与骨干**：冻结环境清单、动作/观测测试、RHPPO 联合概率、序列和终止 bootstrap 测试。
2. **P1 估计器**：先完成 HOT-Tab N0/N1/N2/N3、Oracle VOI、交叉拟合噪声、候选数收敛和 Q 时序对齐。G1–G7 未通过时禁止启动 1000 万步任务训练。
3. **P2 小预算筛选**：单种子短训练依次为 O0 VOI-only、B0 RHPPO、B1 OM-Aux、B2 VariBAD-style、B5 ENS-MI-only、O2 LP×VOI、O3 ENS-MI×VOI、O4 加性。创新算法 O0 优先。
4. **长训练**：按用户指定使用单种子、约 1000 万环境决策；它属于工程筛选实验，不足以替代 V6 原方案要求的多种子正式统计。所有算法共用固定 seed、环境步数、对手协议和评估初始条件。
5. **停止**：若动作条件 ΔNLL、校准、Oracle VOI、零信息假阳性、噪声稳定、MC 收敛或 Q 对齐任一硬门槛失败，只修响应/Q/估计器并复验，不用任务胜率绕过。

## 7. 必须保存的训练指标

每次运行至少保存：环境决策数、墙钟和吞吐、PPO policy/value/entropy/KL/clip/grad、外在与内在回报和优势尺度、响应 NLL/ΔNLL/RMSE/覆盖率/side Brier/ECE、LP、ENS-MI 连续/离散分量、T1/T2/V_CF/V+ 分位数与有效覆盖、Q_A/Q_B TD 和折间差、内在奖励覆盖率/裁剪率、胜负平/超时/坠毁、合法发射机会、请求/接受/拒绝、命中/发射、弹药效率、显存与推理延迟。checkpoint 必须包含 Actor/GRU、双价值头、响应集成及快照、Q_A/Q_B 及目标网络、RMS、优化器和回合折分配状态。
