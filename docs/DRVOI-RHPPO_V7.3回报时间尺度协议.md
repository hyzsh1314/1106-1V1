# DRVOI-RHPPO V7.3：回报时间尺度可学习性协议

## 1. 研究问题

V7.2 表明，即使 Q 输入包含未来 belief、完整观测和低层控制器隐状态，单个高层动作偏差到完整终局回报的映射仍不能稳定泛化。V7.3 因此只检验价值目标时间尺度，不继续搜索状态字段、网络宽度或门槛。

核心问题是：在相同状态和相同动作分支上，外在回报累计到多长时间仍能保持可学习的动作排序，同时具有足够的空战决策意义？

## 2. 冻结目标

同一分支同时保存以下折扣外在回报：

- 3决策步；
- 12决策步；
- 30决策步；
- 120决策步；
- 完整终局。

所有目标使用相同 `gamma=0.99`，终止后按吸收态零回报处理。各时间尺度不能重新采样环境或重新运行不同动作轨迹。

## 3. 表示与角色

1. `registered_v7_1`：失败基线；
2. `full_observation`：未来39维合法观测候选，若通过仍需新响应预测器；
3. `mechanistic_oracle`：未来 belief、未来观测和未来低层隐状态，仅判断目标上界是否可学习。

三种表示使用完全相同的 joint-dueling critic、损失、训练预算和 validation 早停规则。

## 4. 数据隔离

- train seeds：63185、64185；
- validation seed：65185；
- formal-test seed：66185，开发冻结前禁止生成；
- train 共768个上下文，validation 共96个上下文；
- 每个上下文枚举90个动作，仅合法动作进入门禁；
- continuation 固定为 B0 seed85 确定性策略并使用共同随机数；
- 完整终局分支必须真实终止。

## 5. 门禁与选择

每个表示、每个时间尺度独立报告同状态动作排序准确率、上下文 bootstrap 区间、归一化 argmax 遗憾和随机合法动作对照。门槛保持不变：排序准确率不低于0.60且95%区间下界高于0.50；归一化遗憾不高于0.10；并优于随机动作。

研究可用时间尺度不得短于30决策步。选择规则是在 mechanistic oracle 和 full_observation 均通过的时间尺度中选择最大的一个。

- 若所有 oracle 时间尺度失败：`RETURN_TARGET_NO_GO`；
- 若仅3或12步通过：`MYOPIC_ONLY_NO_GO`；
- 若 oracle 在30步以上通过、full_observation 不通过：`REPRESENTATION_PREDICTOR_REQUIRED`；
- 若两者在30步以上共同通过：`HORIZON_FOUND`，只授权新响应目标的开发，不直接授权 formal test、P1Q 或训练。

## 6. 禁止事项

- 不得为不同时间尺度使用不同训练预算；
- 不得在看到 validation 后修改30步研究下限；
- 不得以短期 shaping reward 可拟合直接宣称终局策略改进；
- 不得跳过新的响应预测门禁直接运行 P1Q/O0；
- 开发失败不得生成 formal-test seed。
