# DRVOI-RHPPO V7：WVR响应重建与跨步VOI执行协议

## 1. 冻结边界

V6 的代码、配置、输出和失败结论只读保留。V7 使用 `v7-response-rebuild` 分支、`configs/drvoi_rhppo_v7_wvr.json` 和 `runs/drvoi_rhppo_v7/`，不得覆盖 V6 结果。

环境动力学、武器、外在奖励、终止条件、60 Hz 物理频率和每决策12个物理子步保持冻结。V7只修改响应、校准、跨Δ外在Q、VOI诊断、replay和checkpoint。

## 2. 预注册主问题

主分支 V7-Rel 检验本机动作是否改善未来相对动力学预测，不将其表述为纯对手意图。条件分支 V7-Opp 使用合法观测 `18:21` 的对手NED速度，只在reactive正控制和交互对手上单独验证。

主响应为continuous-only。主跨度固定为Δ=3，即0.6 s；Δ=1和5只作敏感性分析。策略仍每0.2 s决策，动作不保持Δ步。主检验配置不得由命令行覆盖。

## 3. 数据协议

分别采集D-cover、D-onpolicy和D-reactive。每个采集seed、对手和响应分支按完整回合分为train、validation、calibration和test；同一回合不能跨集合。train拟合模型与目标标准化，validation选择容量和早停，calibration只选择概率尺度，test在配置冻结后只评估一次。

D-cover由50%合法联合动作分层覆盖和50%冻结B0策略组成；D-onpolicy只使用成熟冻结B0；D-reactive使用已知延迟和响应方向的交互规则。正式响应统计以完整回合为独立单元。

## 4. 响应门禁

M0/M1使用直接观测无动作/有动作，M2/M3使用同一成熟冻结B0 belief无动作/有动作，M4为同对手与阶段内动作置换，M5为reactive正控制。动作权重置零保证有/无动作初始函数相同，训练预算、早停与成员回合掩码配对。

主G1要求Rel、Δ=3、M3相对M2在D-onpolicy上满足：每维宏平均ΔNLL至少0.05，回合层级配对95%区间下界大于0；正确动作相对置换动作的NLL优势及区间下界均大于0。

目标标准化仅由train回合估计。模型使用有界log-std，标准化空间默认σ范围为 `[1e-3,10]`。响应更新原始梯度超过1000、出现非有限损失或预注册突增时阻断在线VOI。

## 5. 校准门禁

校准尺度按calibration NLL选择，不以test ECE选择。test报告50/90/95%覆盖、PIT、逐维NLL/RMSE、对手×阶段覆盖和边界触及率。总体90%覆盖需在 `[0.85,0.95]`；任一关键维覆盖低于0.75或高于0.98、任一主分层低于0.75时暂停候选使用。

候选采样与验证器共用校准实现。成员均值偏差乘 `sqrt(c)`，成员内部方差乘 `c`，使候选混合总方差严格等于原总方差的 `c` 倍。side不进入主候选。

## 6. 跨Δ外在Q

`X_t=[sg(b_t),a_t,z_(t+Δ)]`，被评估动作为 `a_(t+Δ)`；累计外在回报从该动作开始，覆盖Δ步；下一上下文使用 `z_(t+2Δ)`，bootstrap折扣为 `gamma^Δ`。任何目标、回报或下一上下文跨done/reset均无效。

Q_A/Q_B按完整回合分折且只学习外在奖励。Q-ready不能由固定更新次数触发，必须同时满足每折回合数、元组数、非零回报回合数、留出回报相关、响应敏感正控制和数值健康。

## 7. 在线响应与VOI

在线响应使用完整回合EpisodeReplay和固定成员回合掩码，默认容量2048回合；每次更新50%近期、50%历史并按对手分层。固定probe NLL持续恶化时关闭VOI。

Q-ready为false时VOI必须标记invalid且内在奖励严格为0。Q-ready后至少累计10000个有效上下文，再检查VOI非零覆盖、A/B候选argmax多样性、Top-k翻转、响应shuffle和S=20/100收敛。不得通过增大候选方差或添加噪声制造非零VOI。

## 8. 阶段授权

执行顺序固定为：V7-P0冻结与测试 → P1R响应可识别性 → P1C概率校准 → P1Q外在Q → O0软件/信号烟雾 → 10万至50万步短筛选 → 单种子1000万步工程筛选。

只有前一阶段机器可读门禁通过，后一阶段才可启动。`v7_long_training_authorized`只能由门禁汇总程序设置；当前保持false。O0未证明有效前，不实现或运行O2/O3/O4长训练。

若Rel在三个尺度、direct/belief、cover/onpolicy上均失败，则永久停止DRVOI-Rel。若响应通过但Q-ready失败，阻塞转移到外在价值代理；若O0持续全零或只由shuffle/噪声产生，停止在线DRVOI。

## 9. WVR执行细则

冻结B0采用外在奖励专用RHPPO，训练种子为85、185、285，每个种子使用96环境、256步rollout和41次更新，共1,007,616个环境决策；训练后参数冻结。回合边界同时清零GRU隐状态和上一动作编码，避免上一回合末动作污染新回合belief。每个B0分别对hold、pursuit和evasive执行192局固定对手评估。

D-cover的每个对手与数据划分内部严格保持50%均匀合法动作回合和50%冻结B0回合。均匀动作独立覆盖 `[3,5,3,2]` 四个离散分量，只有fire分量受合法发射掩码约束；一个完整回合内不切换采集策略。

D-reactive是软件正控制，不作为论文对手基线。对手在时刻t读取学习方t-2的动作，并按 `alt=2-alt`、`heading=4-heading`、`speed=2-speed` 做确定性反向响应，fire仅在合法时触发。该规则的已知延迟为2个策略决策，即0.4秒。
