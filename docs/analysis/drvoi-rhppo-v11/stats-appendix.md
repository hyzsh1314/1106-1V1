# 统计附录

## 分析设计与样本量

- 训练重复：每种已训练策略仅 1 个 seed（85）。
- 固定对手评估：每个方法 × 对手 192 局，红蓝各 96 局。
- evaluation seed：10085。
- 主指标：win rate，越高越好。
- 辅助指标：timeout rate（越低越好）、hit/launch（越高越好）、action intervention fraction（描述性）。
- 原始汇总：[exact-summary.csv](exact-summary.csv)。

## 有效与无效的统计推断

本数据不足以估计训练 seed 方差，因此不执行 t-test、ANOVA、Wilcoxon 或跨算法显著性检验。192 个 episode 共享同一个训练 checkpoint，不能替代独立训练重复。由于当前 JSON 没有逐局 outcome 和初始状态标识，也不能执行严格的同初始状态配对检验。

图 1 的误差条为 episode-level 95% Wilson score interval，只回答“该冻结 checkpoint 在当前评估分布中的条件胜率区间”，不表示算法跨 seed 的置信区间。代表性数值如下：

## 描述性效应量

相对 V9，V11.3 的场景级绝对胜率差为 +8.33 pp（Hold）、-6.25 pp（Pursuit）、+21.35 pp（Evasive）；宏平均差为 +7.81 pp。V11.2 的对应差值为 +10.42、-9.38、+26.04 pp；宏平均差为 +9.03 pp。由于缺少跨 seed 重复，这些是描述性绝对效应，不应转换为 Cohen's d 或显著性声明。

## 多重比较与选择偏差

本轮比较了多个仲裁变体，且 V11.1--V11.3 根据同一开发集结果顺序提出。因此不对这些探索性比较报告未校正 p-value。后续应在冻结 V11.3 后使用未接触 evaluation seeds 进行确认，并对预注册的主要对比 V11.3 vs V9 使用 seed-level 配对分析；其他消融采用 Holm 校正。

## 阻断项

1. 单训练 seed 阻断任何“显著优于”或“鲁棒性”结论。
2. 无逐局记录阻断 common-random-number 配对检验和初始几何分层分析。
3. 只含三种脚本对手，不能代表未知策略泛化。
4. 12 步持续阈值来自开发集，不是确认集上的预注册参数。
