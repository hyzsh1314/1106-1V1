## 0. 执行决策

**当前不授权 P1Q、O0、10 万至 50 万步短筛选或 1000 万步 DRVOI 训练。这个停止决定必须保持。**

但也不建议现在就把 DRVOI-Rel 永久否定。V7 已显示动作含有统计上可检测的真实预测信息，只是主效应量不足；同时，reactive 正控制与源码共同指向一个更具体的缺陷：**当前响应模型的上下文没有显式保留完整的因果动作历史，B0 的策略 GRU belief 又可能进一步丢失该信息。**

推荐执行一次范围严格受限的 **V7.1-history-response**：

1. 保持 Rel 响应、主跨度 Δ=3、continuous-only、0.05 nats/维主门槛和 P1C 校准规则不变；
2. 将主上下文由“B0 belief＋当前动作”改为“最近 3 步观测＋最近 3 步动作”的显式短历史；
3. 修复 reactive 正控制的因果动作对齐，以及采集种子层级的统计推断；
4. 使用全新采集种子和全新确认性 test，不得复用 V7 test；
5. 若新主检验仍达不到 0.05 nats/维，或 reactive 正控制在正确对齐后仍失败，则停止当前 WVR 上的 DRVOI-Rel 主线，转向非 DRVOI 的骨干、被动对手建模或分层 PPO 研究。

**只允许这一轮有明确边界的表征重建。不得继续通过更换响应维、遍历更多时间尺度、降低阈值或反复使用旧 test 来寻找阳性结果。**

## 1. V7 结果应如何解释

### 1.1 已经成立的结果

| 层级 | V7 证据 | 客观结论 |
|---|---|---|
| B0 工程完整性 | 3 个外在-only RHPPO 种子均完成 1,007,616 次环境决策 | 可以获得冻结的 1M B0 策略与 belief 工件 |
| 主响应信息 | ΔNLL/维为 0.00808，95% CI 为 `[0.00661, 0.00947]` | 当前模型下，动作信息不是绝对为零，而是效应很小 |
| 动作使用 | 置换增益/维为 0.01863，95% CI 为 `[0.01706, 0.02024]` | 正确动作配对优于同对手、同阶段内的置换动作 |
| 主效应量门禁 | 0.00808 < 0.05 | 主 G1 失败，不能授权 VOI 在线机制 |
| reactive 正控制 | direct 通过，belief 的 ΔNLL 区间跨零 | 当前 B0 belief 没有稳定保留已知动作—响应关系 |
| 主模型数值健康 | 主模型原始梯度峰值 70.26 | 主模型不存在 V6 旧 O0 那种梯度爆炸 |
| 主模型校准 | 总体 90% 覆盖率 0.9072；逐维 0.8952–0.9279；最低对手×阶段覆盖 0.8857 | P1R 失败不能归因于明显的总体方差失校准 |
| 后续授权 | P1Q/O0/短筛选/长训练均未启动 | 门禁被实际执行，而不是只写在文档中 |

最重要的一点是：**V7 的主要失败是效应量失败，不是“置信区间跨零”或“模型完全忽略动作”。** 因此，下一步若继续，应针对信息保留和因果对齐，而不是单纯增加训练样本以缩窄区间。

### 1.2 不能从 V7 推出的结论

- 不能声称“动作对未来相对动力学没有信息”。现有点估计和置换结果反而支持小规模信息存在。
- 不能声称“0.00808 已足够支撑 VOI”。预测 NLL 的小幅改善不自动等于决策相关信息价值，且它没有通过事先规定的工程门槛。
- 不能声称“B0 belief 已经成熟”。1M 步训练完成只说明预算完成；evasive 上 0% 胜率和 84.72% 超时率说明至少在该对手条件下，策略能力仍明显不足。
- 不能声称“direct reactive 通过就证明因果识别完全正确”。当前 direct 模型只输入当前动作，而 reactive 对手显式响应延迟两步的动作。
- 不能把 G1 未通过归因于校准。主模型 P1C 已通过，继续调方差尺度不会解决主要矛盾。
- 不能把 P1Q 代码已经存在解释为 Q 已经可用。该阶段没有运行，且现有 Q-ready 仍有语义缺口，见第 6 节。

### 1.3 建议统一使用的术语

后续文档将当前骨干称为 **“冻结的 1M B0 RHPPO”**，不再无条件称为“成熟 B0”。只有另行预注册骨干能力门槛并通过后，才可使用“成熟”这一描述；不得根据已经看到的 V7 结果追加阈值并追溯判定。

## 2. 源码审查发现的关键问题

### 2.1 P0：reactive 正控制没有显式输入完整的已知因果动作

`benchmarks/collect_drvoi_v7_response_data.py` 中，reactive 对手在时刻 `t` 读取学习方 `t-2` 的动作，并执行确定性反向响应。对于 `Opp、Δ=3` 的目标：

\[
y^{Opp}_{t,3}=v^{Opp}_{t+3}-v^{Opp}_t,
\]

该区间可能受到 `a_{t-2}`、`a_{t-1}` 和 `a_t` 通过对手未来动作产生的影响。然而，`validate_drvoi_wvr_response_v7.py` 的 direct 模型仅接收 `o_t` 与 `a_t`，没有显式接收 `a_{t-2}` 和 `a_{t-1}`。

因此，当前 direct 正控制虽然能够通过，但它可能部分依赖 B0 动作的时间自相关，而不是完整利用真实因果动作。B0 belief 理论上可以保留历史，却没有保证；其实际结果也显示信息保留不稳定。

**V7.1 必须让正控制模型显式接收完整的最近 3 步动作历史。** 对无动作对照，输入相同观测历史，但所有动作通道置零。还需增加“错误延迟动作历史”负控制，确认模型利用的是正确时延，而不是任意动作相关特征。

### 2.2 P0：当前 bootstrap 没有完整落实采集种子层级

`stratified_episode_bootstrap()` 将三个采集文件合并后，只在对手层内重采样回合。它没有按“采集 seed → 对手 → 回合”进行外层聚类重采样，而且采集 seed 与 B0 seed 在运行脚本中一一绑定：

- 6185 对应 B0 seed 85；
- 7185 对应 B0 seed 185；
- 8185 对应 B0 seed 285。

这会产生两个影响：

1. 置信区间可能因忽略共享采集/B0 聚类而偏窄；
2. 采集随机性与 B0 训练种子差异不能完全区分。

这不改变 `0.00808 < 0.05` 的主失败判定，因为点估计已经低于门槛；但会影响“区间显著为正”和 reactive belief 区间是否跨零的精确解释。V7.1 的主推断必须改为独立采集 seed 层级，而不是把数百个回合当作完全独立的外层样本。

### 2.3 P1：B0 策略能力不是响应信息保留的充分证据

三个 B0 的训练和评估工件完整，但任务表现差异明显：

- hold：胜率 31.08%，种子标准差 16.06 个百分点；
- pursuit：胜率 73.61%；
- evasive：胜率 0%，平均超时率 84.72%。

这些结果不证明 belief 一定无用，却足以说明不能把“完成 1M 步”当作语义成熟。V7.1 的主模型不应继续把策略 GRU belief 作为唯一历史表征。显式短历史是更小、更直接的修改；监督式系统辨识编码器只作为后续候选，不与短历史同时堆入首轮主模型。

### 2.4 P1：正式机器可读结果没有随分支入库

在当前固定提交中，`runs/drvoi_rhppo_v7/` 的正式 `validation.json`、门禁 JSON、数据清单和模型文件没有纳入 Git 跟踪；分支中可见的是执行结果 Markdown。大型 `.pt` 数据不必入库，但至少应提交：

- 完整 `validation.json`；
- 各阶段门禁 JSON；
- 数据/模型 SHA-256 清单；
- 运行命令、依赖锁和配置哈希；
- 关键分维、分对手、分采集 seed 的摘要 CSV。

否则，外部审查只能核对汇总 Markdown 与源码，不能独立复核每个灵敏度结果。下一步应立即补齐小型结果工件，而不是只保存最终叙事文档。

### 2.5 P1：当前 Q-ready 的“响应敏感性”不是决策正确性检验

`benchmarks/validate_drvoi_wvr_q_v7.py` 当前通过随机打乱 12 维响应后缀，检查 Q 输出是否变化。只要平均变化超过 `max(1e-4, 0.01×Q_std)` 即可通过。这只能证明网络没有完全忽略响应输入，不能证明：

- Q 对响应的变化方向正确；
- 已知应改变最优动作的响应扰动确实产生正确翻转；
- 不产生翻转时确实应当保持原动作；
- VOI 非零来自真实决策信息，而不是任意响应敏感性。

此外，当前留出回报 Spearman 主要对回合内预测和回报分别取均值后计算，容易受到对手类型、回合长度和回合间难度差异影响，不能替代同一上下文内的动作排序质量。

这些不是现在启动 P1Q 的理由，而是 **V7.1 响应门禁通过后、P1Q 之前必须完成的修复**。

## 3. V7.1 的研究问题与冻结边界

**在保持 Rel、Δ=3 和 D-onpolicy 数据语义不变时，显式短历史与完整因果动作历史，能否使动作条件响应模型的独立 test 效应量达到原定 0.05 nats/维，并通过正确的 reactive 正控制和概率校准？**

该问题只检验“历史信息保留是否是关键瓶颈”，不再同时改变响应目标、对手配置、策略周期和主时间尺度。

- 主响应：Rel 12 维连续增量；

## 4. V7.1 主模型：显式短历史与因果动作历史

### 4.1 输入定义

预注册历史长度 `L=3`，与 reactive 正控制的已知两步延迟及主 Δ=3 对齐。定义：

\[
H_t=[o_{t-2},o_{t-1},o_t],\qquad
A_t=[a_{t-2},a_{t-1},a_t].
\]

每个动作使用 13 维 multi-one-hot。主动作条件模型输入：

\[
x^{H+A}_t=[vec(H_t)\,\|\,vec(A_t)].
\]

无动作配对模型输入：

\[
x^{H+0}_t=[vec(H_t)\,\|\,0_{3\times13}].
\]

两模型使用相同网络、参数初始化、成员回合掩码、训练批次和早停规则；动作输入权重置零，使初始函数一致。回合开始不足 3 步时，观测和动作均使用预注册的零/中性填充及显式有效掩码，不能读取上一回合内容。

### 4.2 网络保持简单

首轮主模型继续使用两层 256 单元 MLP 和 5 成员概率集成，仅把输入替换为显式历史。这样可以尽量把效应变化归因于信息内容，而不是新容量或新架构。

B0 belief＋当前动作保留为 V7 参考模型；当前观测＋当前动作保留为 direct 参考模型。它们不是 V7.1 的主模型，也不得在主模型失败后替代主检验结论。

### 4.3 响应目标和评分不变

\[
y^{Rel}_{t,3}=S^{-1}(z^{Rel}_{t+3}-z^{Rel}_t).
\]

标准化参数只由当前外层训练 seed 的 train 回合估计。主指标仍为：

\[
\Delta NLL_i=NLL^{H+0}_i-NLL^{H+A}_i,
\qquad
\Delta NLL_{macro}=\frac1{12}\sum_{i=1}^{12}\Delta NLL_i.
\]

逐维结果必须完整报告。若只有少数维携带信息，可以在开发集提出后续稀疏响应假设，但不能在 V7.1 确认性 test 后删除弱维并重算主结果。

## 5. V7.1 实验设计

### 5.1 先进行开发集因果诊断，不接触新确认性 test

新增诊断阶段 **P1D-causal-alignment**。它只使用新采集数据的 train/validation，以及独立软件正控制，用于排除实现问题，不用于宣布主假设成功。

| 工作包 | 具体动作 | 通过条件 | 失败处理 |
|---|---|---|---|
| D1 历史缓存 | 保存最近 3 步观测、动作、有效掩码和 episode_id | 回合开头、终止和 auto-reset 均无历史串线 | 只修数据管线 |
| D2 reactive 对齐 | 已知对手响应 `a_{t-2}`，模型显式输入 `a_{t-2:t}` | 正确历史优于错误延迟历史与零动作历史 | 失败则暂停 Rel 科学结论 |
| D3 单头诊断 | 分别置换/删除 alt、heading、speed、fire 历史通道 | 能定位正控制中已知有效动作头 | 若有效头也无法识别，修实现 |
| D4 Rel 可预测性 | 比较当前观测、短历史无动作、短历史有动作的 validation NLL | 短历史至少在 validation 显示稳定配对增益 | 无增益则不进入昂贵确认性训练 |
| D5 数值健康 | 所有开发模型记录原始梯度和方差边界 | 无 NaN/Inf，无未解释 >1000 原始梯度 | 不用裁剪掩盖故障 |

### 5.2 配对干预探针：只用于诊断，不作为在线响应目标

为区分“物理动作效应本身弱”与“模型没有保留动作信息”，建议在开发集状态上做诊断性配对干预：固定同一完整仿真快照、对手控制、低层控制器隐状态与 RNG，分别执行动作 `a` 和中性参考动作 `a^0`，观测：

\[
E_{t,\Delta}(a,a^0)
=S^{-1}\left[z_{t+\Delta}(a)-z_{t+\Delta}(a^0)\right].
\]

报告每个响应维、每个动作头及每个 Δ 的效应 RMS、方向一致性和相对无动作预测误差的比例。该探针回答“动作在相同物理状态下能改变多少未来状态”。

**该反事实差值只能用于离线诊断，不能直接作为在线响应标签或 VOI 输入，因为实际在线决策无法同时观测两个反事实世界。** 若环境尚无完整快照接口，应实现诊断专用 snapshot/restore，并覆盖飞机、导弹、低层隐状态、环境 RNG 和回合状态；不能用仅重置初始位置的方式冒充相同状态。

### 5.3 最小模型矩阵

| 模型 | 观测输入 | 动作输入 | 用途 | 是否主检验 |
|---|---|---|---|---|
| R0/R1 | 当前 `o_t` | 无 / 当前 `a_t` | 复现 V7 direct 参考 | 否 |
| B0-Ref | 冻结 B0 belief | 当前 `a_t` | 复现 V7 主参考 | 否 |
| H0 | 最近 3 步观测 | 全零动作通道 | 新无动作下界 | 主配对的一半 |
| H1 | 最近 3 步观测 | 最近 3 步动作 | 新动作条件模型 | **是** |
| H1-wrong-delay | 最近 3 步观测 | 错位的动作历史 | 时延负控制 | 否 |
| H1-shuffled | 最近 3 步观测 | 同对手×阶段内置换历史 | 动作使用负控制 | 否 |
| Reactive-H0/H1 | 同 H0/H1 | Opp、Δ=3 | 已知因果正控制 | 独立硬门禁 |

D-cover 只用于机制诊断。正式主结论仍来自 D-onpolicy；D-cover 阳性而 D-onpolicy 阴性不能授权在线 VOI。

## 6. 新数据与统计协议

### 6.1 全新确认性数据

建议新采集种子预注册为 `10185、11185、12185、13185、14185`。这些种子不得与 V7 的 6185/7185/8185 混用。V7 所有 test 结果只作为历史结果和 pilot 背景，不参与 V7.1 模型选择、阈值设定或最终区间。

主数据采集先固定一个由协议预先指定的冻结 1M B0 策略，避免采集 seed 与 B0 seed 一一绑定造成完全混杂。建议沿用 seed 85 作为数据生成策略，但选择理由仅为协议固定，不得因为看过其任务表现而挑选。主检验通过后，再用 B0 seed 185/285 做策略种子稳健性复核；复核不通过时仍不能进入在线阶段。

### 6.2 使用留一采集 seed 外层评估

不再把三个采集 seed 的所有回合直接合并后只按回合 bootstrap。采用 5 个采集 seed 的 leave-one-collection-seed-out：

1. 每次完整留出一个采集 seed；
2. 外层训练只使用其余 4 个 seed 的 train/validation/calibration 回合；
3. 其他 seed 的 test 回合也不得进入训练或早停；
4. 留出 seed 的 test 回合整体作为外层 test；
5. 重复 5 次，得到 5 个独立外层 ΔNLL 与置换增益；
6. 主结果报告 5 个外层效应、均值、95% 区间和符号一致数，不以池化回合区间替代。

每个外层模型的训练初始化在有/无动作配对间保持一致。若只使用 5 个 seed 时区间过宽，应在开发阶段根据外层方差预先扩展到 8 个 seed；不能在看到 test 结果后按需增加直到显著。

### 6.3 主统计规则

- 唯一主科学检验：Rel、Δ=3、D-onpolicy、H1 vs H0。
- 主效应：5 个外层采集 seed 的回合等权 ΔNLL/维均值。
- 区间：以外层 seed 为独立单元；主报告使用小样本 t 区间并同时列出全部 seed 效应，回合 bootstrap 只作 seed 内辅助诊断。
- 主门禁：宏平均效应 ≥0.05，95% 区间下界 >0，且至少 4/5 外层 seed 点估计 >0。
- 置换门禁：正确历史相对同对手×阶段置换历史的增益 >0，外层区间下界 >0。
- reactive 正控制：H1 vs H0 的 Opp 效应 >0且区间下界 >0；正确延迟历史必须优于错误延迟历史。
- 多重比较：Δ=1/5、D-cover、逐维和逐对手结果均为次要/探索性；若作独立成功声称，使用 Holm 校正。

## 8. 响应通过后，P1Q 必须先完成的修复

只有第 7 节全部通过才执行本节。当前不提前运行 P1Q。

### 8.1 将随机响应 shuffle 改为结构化决策正控制

保留随机 shuffle 作为“Q 是否读取响应”的辅助指标，但不再让它单独构成 `response_sensitivity_control`。新增两类已知真值测试：

1. **HOT 结构化翻转**：构造已知会使最优后续动作由 `g0` 变为 `g1` 的响应扰动，Q 必须产生正确的 argmax 翻转；
2. **决策无关扰动**：构造已知不改变外在最优动作的响应变化，Q 不应仅因输入变化就产生系统性虚假 VOI。

建议首轮工程验收要求 HOT 预定翻转用例全部通过，且决策无关扰动的零信息门禁保持通过。若 Q 只是对任意响应扰动都敏感，仍视为失败。

### 8.2 增加同一上下文内的动作价值检验

在固定探针上下文上，用共同随机数和外在-only Monte Carlo 回合估计各合法后续动作 `g` 的回报 `Q^{MC}(x,g)`，报告：

\[
\widehat g=\arg\max_g\widehat Q(x,g),\qquad
Regret=Q^{MC}(x,g^*)-Q^{MC}(x,\widehat g).
\]

以及成对动作排序准确率：

\[
Acc_{pair}=P\left[(\widehat Q_g-\widehat Q_h)(Q^{MC}_g-Q^{MC}_h)>0\right].
\]

建议初始工程门槛为：固定探针上的成对排序准确率 ≥0.60 且区间下界 >0.50；归一化 argmax 遗憾 ≤0.10，并显著低于随机合法动作对照。上述数值须先在 HOT/开发探针冻结，再用于 WVR test，不得观察 WVR 结果后调整。

原有回合级 Spearman ≥0.20 可保留为辅助价值语义指标，但不能替代上述同上下文动作排序和遗憾检验。

### 8.3 Q 数据隔离和早停

- Q 使用独立 train/validation/test；validation 可用于早停和目标网络更新频率选择，test 只能在配置冻结后评估一次；
- 双折仍按完整回合隔离，外层采集 seed 不得混入同一训练/test 角色；
- 保持外在-only、跨 Δ 回报、`γ^Δ`、终端不 bootstrap 和完整 checkpoint 测试；
- 目标网络每 epoch 直接复制的当前做法应在 validation 上与滞后更新比较，冻结后方可进入正式 Q test。

## 11. 明确停止规则

出现以下任一情况，即停止当前 WVR 的 DRVOI-Rel 主线：

1. 正确实现完整动作历史后，reactive 正控制仍不能稳定通过；
2. H1 在开发 validation 上没有相对 H0 的稳定正增益；
3. 新确认性主效应仍 <0.05 nats/维；
4. 主效应只在个别采集 seed、个别对手或 D-cover 成立，而 D-onpolicy 主检验不成立；
5. 需要依赖旧 test、删除响应维、降低阈值或挑选 Δ 才能获得阳性结论；
6. 主响应通过后，B0 策略种子复核出现方向反转；
7. Q 只能表现出随机响应敏感，而不能通过结构化决策翻转与外在动作排序检验；
8. O0 的 VOI 仍持续全零，或只在 shuffle/噪声条件下产生非零。

停止后允许转向其他科学问题，但不允许把同一失败路线改名为 V7.2、V7.3 后继续无边界试探。

## 12. 最终建议

当前最有价值的下一步不是“再训练更久”，而是做一次 **因果动作历史是否被正确保留** 的最小检验。V7 的 0.00808 说明动作信息并非绝对为零，给了一次有限重建的理由；但它只有预注册效应量的约 16.2%，加上 reactive belief 失败，又说明原链路不应直接进入 Q 和在线 VOI。

因此，建议严格执行：

**冻结 V7 → 补齐可审计工件 → 短历史 H0/H1 → reactive 正确时延正控制 → 新 seed 留一外层确认 → 通过才修 Q-ready/P1Q，失败即转向。**

这条路线既避免过早放弃一个仍有微弱信息信号的假设，也避免为了挽救 DRVOI 而不断修改目标、阈值和实验解释。
